--------------------------------------------------------------------------------
專案目標
--------------------------------------------------------------------------------
根據 new_vco.odt 的需求，實作電壓控制環形振盪器VCO，並測試不同控制方案
以獲得理想的KVCO特性曲線（頻率 vs 控制電壓）。

--------------------------------------------------------------------------------
主要成果
--------------------------------------------------------------------------------

✓ 實作3種控制方案
  - 雙邊控制（PMOS + NMOS同時控制）
  - PMOS-Only單邊控制
  - NMOS-Only單邊控制

✓ 測試方案4（尺寸調整）
  - V1: PMOS主導 (W=3.0/0.42)
  - V2: NMOS主導 (W=0.42/3.0)
  - V3: 極端PMOS (W=5.0/0.42)
  
✓ 測試方案3（單邊控制）
  - PMOS-Only: 0.7-1.2V穩定區間，單調遞減
  - NMOS-Only: 0.65-1.8V穩定區間，單調上升

✓ 完整的測試框架
  - 互動式模擬腳本
  - 批次自動測試
  - 結果自動繪圖（支援中文）
  - 多版本比較分析

✓ 完善的文檔
  - 設計指南
  - 測試結果總結
  - 快速開始指南
  - 提交檢查清單

--------------------------------------------------------------------------------
測試結論
--------------------------------------------------------------------------------

方案4（尺寸調整）: ❌ 失敗
  → 無法消除雙邊控制的峰值特性
  → 結論: 雙邊控制本質上會在中間電壓產生峰值

方案3（單邊控制）: ⚠️ 部分成功
  → 在穩定區間內可獲得單調曲線
  → 限制: 極低電壓有不穩定現象，控制範圍較小

推薦方案:
  → 使用PMOS-Only控制 (0.7-1.2V範圍)
  → 或考慮專業的current-starved設計
