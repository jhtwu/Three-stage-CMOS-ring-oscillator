================================================================================
快速導航
================================================================================

🚀 快速開始:
   1. 閱讀: README_FINAL.md
   2. 基本模擬: ngspice -b vco_circuit_jpg.cir
   3. KVCO 掃描: ngspice -b vco_kvco_circuit_jpg.cir
   4. 生成圖表: python3 plot_circuit_jpg.py

📖 詳細文檔:
   - 實驗報告: VCO_EXPERIMENT_REPORT.md
   - 快速參考: VCO_QUICK_REFERENCE.md
   - 專案總覽: README_FINAL.md

🔧 修改電路:
   - 編輯: vco_circuit_jpg.cir
   - 查看圖: xschem vco_dual_bias.sch (或 ./run_xschem.sh)

📊 查看結果:
   - 數據: vco_kvco_circuit_jpg_results.csv
   - 圖表: vco_circuit_jpg_plot.png

================================================================================
重要成果
================================================================================

✓ 單調遞減 KVCO 曲線（0.7~1.2V 範圍）
✓ 頻率範圍: 0.25 ~ 3.68 GHz
✓ KVCO: -6.86 GHz/V (平均)
✓ 電路結構簡單，易於實現
